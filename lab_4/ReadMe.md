
## Отчёт по лабораторной работе №4
#### Решение задач многомерной условной оптимизации методом множителей Лагранжа

## Цель
Освоить полный цикл решения многоэтапной оптимизационной задачи: от математической постановки и вывода рекуррентного соотношения Беллмана до ручных вычислений, программной реализации и проверки результата.

## 3.1. Математическая постановка
### 1. Исходные данные
Начальный инвестиционный портфель состоит из следующих активов:

| Актив | Начальное количество, руб. | Размер одного пакета, руб. | Комиссия за пакет, руб. |
|---|---:|---:|---:|
| Ценная бумага 1 (ЦБ1) | 100 | 25 | 1 |
| Ценная бумага 2 (ЦБ2) | 800 | 200 | 14 |
| Банковский депозит | 400 | 100 | 5 |
| Свободные денежные средства | 600 | — | — |
| **Итого** | **1900** | | |

### 2. Переменные решения
На каждом этапе вводятся три целочисленные переменные:

- \(u_{1k}\) — количество пакетов ЦБ1;
- \(u_{2k}\) — количество пакетов ЦБ2;
- \(u_{3k}\) — количество пакетов депозита.

Положительное значение переменной означает покупку, отрицательное — продажу, нулевое — отсутствие операций.

### 3. Целевая функция
Необходимо максимизировать ожидаемый капитал в конце третьего этапа.  <img width="94" height="28" alt="image" src="https://github.com/user-attachments/assets/7f240362-9185-412d-9c1d-fcbd945b7bf4" />

Конечный капитал равен сумме всех активов и свободных денежных средств.

### 4. Ограничения
Количество пакетов должно быть целым числом.
Одновременная покупка и продажа одного актива не допускаются.
После операций должны соблюдаться минимальные остатки активов.
Свободные денежные средства не могут быть отрицательными.
Продажа активов выполняется до покупки новых.

### 5. Начальное состояние

Начальное состояние инвестиционного портфеля:
s_1=(100; 800;400; 600)
где первые три компонента — стоимость активов, последний компонент — свободные денежные средства.

### 6. Условия завершения процесса
Процесс заканчивается после третьего этапа и реализации последнего рыночного сценария. После этого рассчитывается конечный капитал.

### 7. Смысл результата
Нужно найти такую последовательность покупок и продаж, которая обеспечит максимальный ожидаемый капитал по итогам трёх этапов.
