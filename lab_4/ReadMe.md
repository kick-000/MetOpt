## 2. Программная реализация задачи

Программа выполняет следующие действия:

1. Задаёт начальные параметры портфеля, размеры пакетов, комиссии и минимальные остатки активов.
2. Формирует возможные управляющие воздействия: покупку, продажу или сохранение текущего количества активов.
3. Проверяет допустимость каждого действия с учётом ограничений по активам и свободным денежным средствам.
4. Рассчитывает стоимость портфеля после реализации каждого рыночного сценария.
5. С помощью рекурсивной функции Беллмана определяет оптимальные действия на каждом этапе.
6. Восстанавливает оптимальную стратегию и строит полное дерево возможных исходов.
7. Рассчитывает ожидаемый конечный капитал, чистый доход, доходность, вероятность убытка, а также минимальный и максимальный доход.

Для проверки результатов дополнительно реализовано сравнение полного и сокращённого перебора допустимых действий на втором этапе.

По результатам работы программа выводит оптимальную стратегию, решения для каждого рыночного сценария и таблицу из 27 конечных исходов. Также предусмотрено сохранение результатов дерева в файл `tree_outcomes_bellman.csv`.

Программная реализация позволяет автоматизировать вычисления и проверить правильность полученной оптимальной стратегии.
## 3. Сравнение ручного и программного решения

Ручное и программное решения дали одинаковую оптимальную стратегию на первых двух этапах: сначала купить 23 пакета ЦБ1, а затем в зависимости от сценария продать 31, 27 или 20 пакетов соответственно.

Различие возникло на третьем этапе. Программа учитывает, что после негативного сценария второго этапа остаток ЦБ1 может оказаться ниже минимально допустимого. Поэтому в таких случаях необходимо купить один пакет ЦБ1. В первоначальном ручном решении эта особенность не учитывалась.

В результате получены следующие показатели:

| Показатель | Ручное решение | Программное решение |
|---|---:|---:|
| Ожидаемый конечный капитал | 2034,24 | 2033,99 |
| Чистый доход | 134,24 | 133,99 |
| Доходность | 7,0652% | 7,0520% |

Таким образом, программное решение уточнило ручные расчёты и учло все необходимые ограничения. Математическое ожидание, рассчитанное по дереву исходов, совпало со значением функции Беллмана, что подтверждает согласованность результатов.

## 4. Заключение

В ходе лабораторной работы № 4 была рассмотрена задача управления инвестиционным портфелем в условиях неопределённости с применением метода динамического программирования.

Была построена математическая модель, выведено рекуррентное соотношение Беллмана и выполнены ручные расчёты. На языке Python разработана программа, реализующая поиск допустимых решений, расчёт состояний портфеля и восстановление выбранной стратегии.

Для выбранной стратегии получены следующие результаты: начальный капитал — 1900 руб., ожидаемый конечный капитал — 2033,99 руб., ожидаемый прирост — 133,99 руб., ожидаемая доходность — 7,05 %, вероятность убытка — 19 %.

Программа сформировала дерево из 27 конечных сценариев, сумма вероятностей которых равна единице. Проверка полного и сокращённого перебора подтвердила совпадение результатов для трёх рассмотренных состояний, однако не доказала глобальную оптимальность для всех возможных стратегий.

Таким образом, в ходе работы были освоены основные принципы динамического программирования и его применения для решения многоэтапных задач оптимизации.
