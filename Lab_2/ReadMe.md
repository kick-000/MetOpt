## Отчёт по лабораторной работе №2
Поиск глобального экстремума функции методом ломаных (Пиявского)

#### Расчет константы Липшица $L$
расчёт константы Липшица $L$:
Для гарантии сходимости метода требуется точно оценить максимальную скорость изменения функции $L = \max_{x \in [a, b]} \vert{}f'(x)\vert{}$. Программа выполняет это символьно: берется первая $f'(x)$ и вторая $f''(x)$ производные, находятся критические точки производной внутри отрезка, и среди них (включая границы $a$ и $b$) выбирается максимальный модуль первой производной.

#### Основнрй цикла алгоритма Пиявского

1. Сортировка точек: На каждой итерации список уже проверенных точек (x_i, f(x_i)) сортируется по возрастанию аргумента x.
2. Поиск нижней вершины ($z, G$): Программно перебираются все соседние интервалы $[x_i, x_{i+1}]$. На каждом интервале по формулам пересечения конусов Липшица вычисляются координаты нижней вершины ломаной $(z, G)$. Среди них выбирается абсолютный минимум $G_{\min}$ и соответствующий аргумент z.
3. В найденной точке z вычисляется реальное значение исходной функции $f(z)$, после чего пара $(z, f(z))$ добавляется в общий массив точек.
4. Проверка критерия остановки: Вычисляется разность между наименьшим найденным значением функции $f_{\min}$ и нижней оценкой $G_{\min}$. Если погрешность $f_{\min} - G_{\min} < \varepsilon$ (или достигнут лимит в $10\,000$ итераций), цикл прерывается, а найденный $x^*$ принимается за глобальный минимум.
